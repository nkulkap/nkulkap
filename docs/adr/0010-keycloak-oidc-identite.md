# ADR-010 — Keycloak (OIDC) pour l'identité

- Statut : Accepté
- Date : 2026-10-21
- Source : cahier des charges, section 3

## Contexte

Utilisateurs concernés : back-office, collecteurs, appareils.

## Décision

Keycloak (OIDC) pour l'identité. Fineract en mode serveur de ressources OAuth2.

## Conséquences

Double authentification pour les rôles sensibles.
