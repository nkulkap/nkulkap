# ADR-011 — Hébergement au Cameroun par défaut

- Statut : Accepté
- Date : 2026-10-21
- Source : cahier des charges, section 3

## Contexte

La loi n° 2024/017, applicable depuis le 23 juin 2026, soumet le transfert de données personnelles à l'étranger à une autorisation préalable **[À VÉRIFIER : texte officiel]**.

## Décision

Hébergement au Cameroun par défaut : l'offre SaaS est hébergée dans un centre de données au Cameroun.

## Conséquences

L'installation sur site reste possible.
