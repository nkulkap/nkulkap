# ADR-009 — PostgreSQL comme base unique, Apache Kafka en mode KRaft

- Statut : Accepté
- Date : 2026-10-21
- Source : cahier des charges, section 3

## Contexte

Un seul SGBD à exploiter, supporté par Fineract. Kafka est le transport des événements externes de Fineract.

## Décision

PostgreSQL comme base unique, Apache Kafka en mode KRaft.

## Conséquences

Non précisé dans le cahier des charges.
